# 第1章：鸿蒙觉醒

夜色如墨，月隐星沉。

李家演武场上，月光洒在斑驳的血迹上，映照着一个狼狈的身影。李长生躺在冰冷的石板上，肋骨断了三根，鲜血染红了衣襟，但他依然死死咬着牙，不让一丝痛呼逸出嘴角。

"废物！李家的耻辱！"

"十八岁了还停留在炼体期，真是丢尽了我李家的脸！"

"哈哈，连新入门的外门弟子都打不过，还敢称自己是天才？"

嘲讽声如同利刃，一刀刀割在他的心上。想当年，他出生时天生异象，紫气东来三万里，被誉为千年一遇的鸿蒙道体，整个青阳城为之震动。可如今，却成了人人都可以踩一脚的废物。

"为什么......"李长生握紧拳头，指甲深深嵌入掌心，"我修炼的《引气诀》明明是玄品功法，为什么就是无法突破？"

这十八年来，他每日苦修十个时辰，风雨无阻，所受的苦楚比任何人都要多。可修为却始终停留在炼体期九重，距离凝血期只有一线之隔，却如天堑般无法逾越。

就在这时，一个冰冷的声音响起："长生，我来退婚。"

赵如烟一袭红裙，美艳如花，但眼神却比寒冰还要冷。她高高在上地看着地上的李长生，如同看着一只蝼蚁。

"你我本就不是一个世界的人。如今我是内门弟子亲传，而你......"她轻蔑一笑，"一个连炼体期都无法突破的废物，不配做我的夫君。"

这已经是第三个月，第三个人当众羞辱他了。李长生缓缓站起身，擦去嘴角的血迹，直视着赵如烟："婚书呢？"

"撕了。"赵如烟扬了扬眉，"从今往后，你我再无瓜葛。希望你好自为之。"

看着她离去的背影，李长生的心在滴血。不是因为失去一个貌美的未婚妻，而是因为这再一次的打击，让他对修炼之路产生了深深的怀疑。

难道我李长生，真的注定是个废物？

拖着伤痕累累的身体回到房间，李长生盘膝坐下，按照《引气诀》的法门开始修炼。灵气入体，却如同泥牛入海，毫无反应。

"啊——！"他痛苦地嘶吼，一拳轰在墙上。

鲜血顺着指缝流下，滴落在胸前佩戴的一块古朴玉佩上。这玉佩是他出生时就挂在身上的，父母说这是李家的传家宝。

就在鲜血浸染玉佩的瞬间，异变陡生！

"嗡——"

玉佩爆发出璀璨的紫光，将整个房间照得亮如白昼。一股无法形容的恐怖威压从玉佩中散发出来，虚空中浮现出一个顶天立地的伟岸身影。

这身影模糊不清，只能看到他盘坐于九天之上，脚下是无数崩塌的星河，周身紫气浩荡三万里，一呼一吸间，万道臣服！

"呵呵......"一声苍老的轻笑响起，带着万古的沧桑，"没想到，本座的残魂，竟然等到了血脉传人......"

李长生震惊地看着眼前的一切，这威压让他几乎要跪下，但他咬紧牙关，勉强站立。

"您是......"

"吾乃鸿蒙！"那个声音充满了威严，"万古之前，九天第一强者。而这枚玉佩，正是我的一缕精血所化。"

"鸿蒙道人？！"李长生倒吸一口冷气。这个名字，在古老的传说中，是所有修炼者的神话！

"你所修炼的《引气诀》，乃是本座创下的法子，专门用来磨砺鸿蒙道体的。不历经十八年苦修，不尝遍世间冷暖，怎能承载鸿蒙传承？"鸿蒙的声音带着欣慰，"如今，你心志已坚，是时候觉醒了！"

话音落下，一道紫色的光芒射入李长生的眉心！

轰！

庞大的信息洪流涌入他的脑海，那是《鸿蒙混沌诀》的完整功法！比《引气诀》霸道百倍，深奥千倍！

"此法，分九层，对应九重天。第一层，引气入体，筑基炼神。第二层......"

随着功法运转，李长生体内的神秘枷锁寸寸断裂！被封印了十八年的力量，终于苏醒了！

炼体期九重......突破！

凝血期初期......突破！

凝血期中期......突破！

短短一个时辰，李长生的修为一路高歌猛进，直达凝血期后期！体内的灵力如同江河奔腾，每一寸肌肉都充满了爆炸性的力量！

"哈哈哈！"李长生仰天长啸，声震九霄，"十八年的屈辱，今日终于一扫而空！"

他握紧拳头，感受着体内澎湃的力量，眼中燃烧着复仇的火焰。

"赵如烟，欺我辱我之人，我李长生必将十倍奉还！"

"血刃宗，灭我满门之仇，我必让你们血债血偿！"

鸿蒙道人满意地点头："很好。记住，修炼之路，逆天而行，当有宁可我负天下人，休教天下人负我的霸气！去吧，让九天十域，都记住你李长生的名字！"

紫光散去，房间恢复了平静。但李长生的双眸，却亮如星辰。他推开门，沐浴在月光下，感受着脱胎换骨的自己。

从今往后，他不再是废物李长生，而是要踏上九天，成就万古第一神的存在！
