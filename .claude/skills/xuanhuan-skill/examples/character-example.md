# 人物小传

## 主角团

**李长生**（主角）

十八岁，身材挺拔，剑眉星目，面容俊朗，双眸深邃如星空，周身隐隐有鸿蒙紫气缭绕。性格坚毅不屈，杀伐果断但重情重义，行事张扬却不失谨慎。天生鸿蒙道体，因修炼《引气诀》无法突破，后获得鸿蒙道人传承，修《鸿蒙混沌诀》，一日千里。从炼体期废柴，一路逆天改命，最终成就真仙之境。

**林清雪**（女主）

十九岁，绝世容颜，肌肤如雪，长发如瀑，气质清冷如冰山雪莲，是青云宗第一美女。性格外冷内热，对陌生人冷若冰霜，对在意的人温柔如水。天生寒冰灵体，修炼《玄冰诀》，是青云宗宗主亲传弟子，圣女身份。初期与李长生多有摩擦，后逐渐被其坚毅打动，产生情愫。

**萧炎**（兄弟）

二十岁，身材魁梧，面容刚毅，眼神炽热如火，周身气势豪迈。性格豪爽仗义，为兄弟两肋插刀，战斗时勇猛无畏。火系天赋异禀，修炼《焚天炎武诀》，与李长生在青云宗相识，成为生死兄弟。一路并肩作战，最终成就洞虚期强者。

## 反派角色

**血无涯**（血刃宗宗主）

六十岁，面色阴森，双目血红，周身血气缭绕，给人以邪异恐怖之感。性格残忍嗜血，为达目的不择手段，修炼邪功《血河魔典》。化神期修为，十年前为夺鸿蒙秘藏，率众灭李家满门，是李长生前期的最大仇敌。最终被觉醒的李长生以禁忌神通同归于尽。

**张无忌**（青云宗长老）

五十岁，道貌岸然，仙风道骨表象下隐藏着阴险毒辣。性格嫉贤妒能，心胸狭隘，因嫉妒李长生天赋而处处针对。凝血期修为，暗中与血刃宗勾结，多次设计陷害李长生。阴谋败露后，被李长生当众斩杀，身败名裂。

## 重要配角

**鸿蒙道人**（传承者）

万古前的第一强者，只剩一缕残魂寄存在鸿蒙血脉中。性格淡然中带着对后辈的期许，见识广博，底蕴深厚。真仙修为，在李长生最绝望时出现，传授《鸿蒙混沌诀》，指点其修炼之路。是李长生最大的机缘和引导者。

**李青天**（青云宗宗主）

七十岁，鹤发童颜，目光如电，威严深重，正道魁首的气度尽显。性格公正严明，爱护门下，对李长生青眼有加。合道期修为，在关键时刻多次庇护李长生，是其重要的靠山。后来看出李长生的不凡，倾力培养。

## 其他角色

**王腾**：二十岁，李家外族子弟，傲慢自大，炼体期修为，初期欺压主角，后被一招击败。

**赵如烟**：十八岁，李长生未婚妻，拜金势利，因主角是废柴而退婚，后悔莫及。

**张三丰**：神秘老人，身份不明，偶尔出现指点，实力深不可测。

## 势力介绍

**青云宗**：东域三大宗门之一，正道门派，宗主李青天为合道期强者，与主角关系友好。

**血刃宗**：魔道大宗，宗主血无涯为化神期魔头，擅长血魔功，与主角有灭门之仇。

**李家**：青阳城三大家族之一，曾显赫一时，十年前没落，只剩李长生一脉。

**皇朝**：中州统治者，掌控数个州域，实力最强，正在秘密调查仙界遗迹。
