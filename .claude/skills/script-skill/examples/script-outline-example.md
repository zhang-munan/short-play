剧名《好一个乖乖女》
集数: 70集
编剧: 张编剧

一、剧情简介

表面温顺乖巧的豪门千金鹿鸣于，实则是暗夜组织的顶级杀手。为报父母之仇，她隐藏身份潜入仇家段氏集团，与冷酷霸总段休冥展开了一场充满欺骗与真情的较量。当爱情与仇恨交织，当真相逐步揭开，两个注定对立的人能否突破命运的桎梏？

二、人物小传

【女主】
姓名: 鹿鸣于
年龄: 24岁
外貌: 清纯可人，气质温婉，黑长直发型，常穿白色连衣裙
性格: 表面乖巧柔弱，实则冷酷果决，心思缜密，擅长伪装
简介: 鹿氏集团唯一幸存者，12岁时全家被段氏所害，后被暗夜组织收养培养成顶级杀手。她以温顺乖巧的形象示人，实则内心充满仇恨，一直在寻找复仇机会。擅长格斗、射击、伪装，精通多国语言。

【男主】
姓名: 段休冥
年龄: 28岁
外貌: 身材高大，面容俊朗，眉眼深邃，气质冷酷
性格: 表面冷酷无情，实则内心柔软，重情重义，占有欲强
简介: 段氏集团现任总裁，人称"肆少"。从小就背负着家族的期望，外表冷酷是为了隐藏内心的孤独。对鹿鸣于一见钟情，却被她的"温柔"外表所迷惑。当发现鹿鸣于的真实身份后，陷入了痛苦的抉择。

【反派】
姓名: 段天成
年龄: 55岁
外貌: 斯文败类，戴金丝眼镜，笑意不达眼底
性格: 阴险狡诈，心狠手辣，为达目的不择手段
简介: 段氏集团董事长，段休冥的父亲。当年为夺取鹿氏集团，设计灭门。表面慈祥和蔼，实则心机深沉。一直在暗中操控着一切，包括段休冥的婚姻。

【主要配角2】
姓名: 林晚晴

三、大纲

开端（1-10集）
鹿鸣于以新娘身份出现在段詹祥的婚礼上，实则是为了接近段休冥。婚礼现场，她穿着不合身的婚纱，表现得温顺乖巧，却在无人注意时露出了与外表不符的眼神。段休冥第一次见到她就产生了兴趣，在包间发现了她画的骷髅婚礼图，意识到这个"乖乖女"并不简单。鹿鸣于主动提出"睡一个"的挑衅，让段休冥震惊，也为两人后续的关系埋下伏笔。

付费点：第1集结尾段休冥对鹿鸣于产生怀疑；第5集结尾鹿鸣于的真实身份初露端倪。

发展（11-50集）
鹿鸣于成功进入段家，开始了她的复仇计划。她一边维持着乖乖女的形象，一边暗中收集段天成的罪证。段休冥在相处中逐渐爱上鹿鸣于，却又多次发现她的可疑之处。两人在试探与心动中反复拉扯。詹祥开始调查鹿鸣于的背景，发现了她与暗夜组织的联系。林晚晴多次陷害鹿鸣于，反而让段休冥更加保护她。

关键转折：第20集鹿鸣于第一次执行刺杀任务；第35集段休冥发现父母的死亡真相；第50集鹿鸣于的杀手身份暴露。

高潮（51-60集）
所有真相被揭开，鹿鸣于和段休冥陷入对立。段天成开始疯狂报复，绑架了鹿鸣于。段休冥为救鹿鸣于与父亲决裂，最终在鹿鸣于的帮助下，收集了段天成的所有罪证。在最终的决战中，鹿鸣于放弃了复仇的机会，选择了原谅。

付费点：第55集段天成绑架鹿鸣于；第60集段休冥为救鹿鸣于身受重伤；第65集真相大白。

结局（61-70集）
段天成受到法律制裁，段氏集团改组。鹿鸣于放下了仇恨，选择和段休冥在一起。两人重新开始，鹿鸣于怀孕，迎来了圆满的结局。詹祥接管了暗脉文将的位置，林晚晴也得到了应有的惩罚。
