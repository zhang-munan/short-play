# 小说创作项目

这是一个模块化的小说创作项目，支持多种类型的小说创作，包括现代言情和玄幻小说。每个模块都是独立的，有自己的技能包和创作助手。

## 项目结构

```
short-play/
├── .claude/                    # 根目录配置
│   ├── CLAUDE.md              # 项目总入口配置
│   ├── skills/                # 共享技能包
│   │   └── script-skill/      # 剧本创作技能包
│   └── agents/                # Agent配置
│       └── manhua-alignment.md
│
├── xianyan-module/            # 现代言情创作模块
│   ├── .claude/
│   │   ├── CLAUDE.md          # 模块专用配置
│   │   ├── skills/
│   │   │   └── xianyan-skill/ # 现代言情创作技能包
│   │   └── agents/
│   └── novels/                # 小说存放目录
│           └── <小说名>/
│
├── xuanhuan-module/           # 玄幻小说创作模块
│   ├── .claude/
│   │   ├── CLAUDE.md          # 模块专用配置
│   │   ├── skills/
│   │   │   └── xuanhuan-skill/ # 玄幻小说创作技能包
│   │   └── agents/
│   └── novels/                # 小说存放目录
│           └── <小说名>/
│
└── README.md                  # 本文档
```

## 快速开始

### 1. 创作现代言情小说

进入现代言情模块：
```bash
cd xianyan-module
```

按照提示开始创作你的都市言情小说。

### 2. 创作玄幻小说

进入玄幻小说模块：
```bash
cd xuanhuan-module
```

按照提示开始创作你的玄幻修真小说。

## 模块说明

### xianyan-module（现代言情模块）
- **创作类型**：都市情感言情小说
- **风格特点**：现代、细腻、情感化
- **功能**：完整的故事创作流程，从大纲到章节正文

### xuanhuan-module（玄幻小说模块）
- **创作类型**：仙侠修真玄幻小说
- **风格特点**：史诗、热血、想象力丰富
- **功能**：完整的故事创作流程，包含修炼体系设计

### script-skill（剧本创作技能包）
- **功能**：将小说改编为短剧剧本
- **适用范围**：所有模块创作的小说
- **输出**：标准格式的短剧剧本

## 使用说明

1. 每个模块都是独立的创作环境
2. 进入模块后，按照对应的CLAUDE.md文件中的指引操作
3. 每个模块都有自己的novels目录存放创作的小说
4. 剧本改编功能需要使用共享的script-skill

## 注意事项

- 各模块之间相互独立，不会互相影响
- 技能包文件已经整合到对应模块中
- 创作的作品保存在各自模块的novels目录下
- 剧本功能需要使用根目录的script-skill

## 技术支持

如有问题，请查看各模块下的.claude/CLAUDE.md文件获取详细使用说明。
