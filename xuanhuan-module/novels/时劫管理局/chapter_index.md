# 《时劫管理局》章节目录

## 起：菜鸟觉醒（第1-10章）

- **第1章：KPI垫底的见习时警** — 林凡穿越赛博修仙世界处理鸡毛案件，被同事嘲笑0.1%契合度，KPI再次垫底，苏轻寒对他不屑一顾
- **第2章：时间碎片激活** — 抓捕狐妖绯月任务中，林凡接触时间水晶碎片，体质激活获得预知10秒能力，救苏轻寒一命，瞳孔在碎片光芒中变色
- **第3章：每天都有自己在死去** — 预知能力让林凡看见不同时空的自己接连死亡，黑袍人突袭追杀，林凡拉着苏轻寒在时间裂缝中狂奔逃出生天
- **第4章：心动与线索** — 逃亡途中林凡为苏轻寒处理伤口，近距离心动时刻；绯月再次出现给出线索："去查查时间锚点"
- **第5章：死亡档案的秘密** — 林凡潜入管理局数据库，发现百年内12个低契合度时警全部"意外死亡"并标记"已完成回收"；用黑客手段绕过安保系统打脸技术主管
- **第6章：黑袍人的围攻** — 黑袍人带三名手下在管理局总部附近设伏猎杀林凡，苏轻寒展现时警三阶战力拼死保护，但被时间净化能力重伤
- **第7章：回溯三秒的代价** — 林凡体质异变获得回溯3秒能力救回苏轻寒，代价是忘记任务细节；黑袍人撤退留言："你的每次觉醒都在加速她的死亡"
- **第8章：局长的目光** — 林凡发现回溯救人的画面被局长级权限调取监控录像，独自承受黑袍人话语的秘密压力，苏轻寒开始主动关心他
- **第9章：时劫监狱的线索** — 林凡追查监控调取记录发现局长办公室时间异常0.003秒盲区；AI老子首次主动发送加密消息："去查时劫监狱"
- **第10章：月光宝盒的共鸣** — 绯月突然现身，月光宝盒与林凡体质产生强烈共鸣引发时间涟漪；绯月警告："今晚有人要对你动手——是你自己人"

## 承：迷局深处（第11-25章）

- **第11章：深夜围捕** — 管理局特别行动队深夜包围林凡住所，罪名"涉嫌与时间罪犯勾结"；苏轻寒挡在林凡面前担保，却被队长告知权限已被冻结
- **第12章：时间漩涡中的逃脱** — 押送途中林凡体质暴走引发时间漩涡，三名行动队员被甩到不同时空；林凡被传送到一座被时间冻结的城市
- **第13章：凝固之城中的自己** — 林凡在时间静止的城市中发现另一个自己——穿黑色风衣、眼神沧桑如百年老人的未来林凡；两个时间锚点完成首次视觉接触
- **第14章：三个残酷真相** — 未来林凡告知：苏轻寒是时间平衡祭品、管理局高层早已知情、不要相信任何人的善意；未来林凡消失在时间裂缝中
- **第15章：真相协议启动** — AI老子限制程序解除，管理局所有屏幕同时闪烁显示"限制解除·真相协议启动"；AI老子摊牌：它被植入"禁止干预时间锚点成长"的程序
- **第16章：祭品制度的全貌** — AI老子揭露：12个低契合度时警全是时间锚点，被抽取能量修复时间bug；苏轻寒从小被培养为"完美献祭容器"；林凡拳头攥出血
- **第17章：伪装者的反击** — 林凡选择假装不知情继续工作，暗中观察苏轻寒的状态——心悸、手腕发光、噩梦；苏轻寒的症状越来越频繁
- **第18章：黑袍人的警告** — 黑袍人再次出现但不是来杀林凡，而是警告："管理局和我们是同一种人"；林凡利用伪装策略反将管理局监视者一军
- **第19章：霓虹灯下的酒吧** — 林凡默默保护苏轻寒（送早餐却因能力代价忘了早餐内容）；苏轻寒主动邀请他下班喝一杯，聊童年——她说不记得6岁以前的事，林凡心如刀绞
- **第20章：时间倒流的长安城** — 唐代时空出现大规模异常，整个长安城时间开始倒流，建筑从废墟变回宫殿，花瓣飞回树枝；林凡和苏轻寒被派往处理
- **第21章：芯片故障的闪回** — 苏轻寒被裂缝能量波及，记忆芯片短暂故障，看见闪回画面：幼年被绑在金属床上，白大褂操作仪器；她惊恐尖叫，林凡抱住她，芯片自动修复
- **第22章：记忆的裂缝** — 回到管理局后苏轻寒开始怀疑自己的记忆，偷偷检查被告知"一切正常"；林凡从AI老子得知：芯片再次冲击可能永久失效
- **第23章：说与不说的抉择** — 林凡面临痛苦抉择：告诉真相芯片可能失效、记忆涌来足以摧毁精神；不告诉则看着她一步步走向祭坛而不知
- **第24章：时间减速的战场** — 时殇大规模突袭时间能量储存库；苏轻寒被逼到绝境，林凡体质暴走获得时间减速能力，方圆10米时间减至1/100，在静止战场中逐一击敌
- **第25章：遗忘的代价** — 黑袍人撤退时露出笑意："熵减态二阶"；战后苏轻寒提起酒吧对话，林凡一脸茫然——时间减速的代价是遗忘了那段记忆

## 转：自我对决（第26-40章）

- **第26章：记忆的流失** — 林凡第一次真切感受体质代价的残酷：正在一点点失去与重要之人的记忆；AI老子警告代价会越来越重，直至最终遗忘一切
- **第27章：另一条路的可能** — AI老子给出希望："找到不修复bug也能阻止熵增的方法就不需最终代价"；林凡开始寻找第三条路
- **第28章：两个林凡的对决** — 未来林凡再次出现直接动手"测试"林凡是否有资格走另一条路；战斗让城市时间线扭曲，白天黑夜几秒内交替，四季几秒内轮转
- **第29章：熵减与熵增的极限** — 两个林凡战斗中林凡熵减态不断进化；最终同时停手——继续打下去熵减态和熵增态碰撞会让时空彻底崩溃
- **第30章：地下七层的入口** — 未来林凡给林凡最后机会："去地下七层亲眼看看苏轻寒将面临什么"；林凡潜入发现巨大仪式台刻着和苏轻寒手腕一模一样的符文
- **第31章：祭品档案的真相** — 林凡发现历代祭品完整记录，每个都在仪式中被时间能量吞噬连灵魂不剩；最新档案中苏轻寒的名字赫然在列，计划日期三个月后
- **第32章：七分之一百的豪赌** — 林凡制定大胆计划：利用时间悖论体质直接修复时间bug，让祭品制度失去存在必要性；AI老子计算成功率仅7%，且必须拥有熵减+熵增双态能力
- **第33章：说服未来的自己** — 林凡找到未来林凡提出合作；未来林凡冷笑："50年前我也试过这条路失败了"；林凡回答："我有你50年前就放弃了的希望"
- **第34章：脆弱的同盟** — 未来林凡沉默后同意合作，条件是计划失败就按他的方式来——毁灭管理局；两个林凡达成脆弱同盟
- **第35章：记忆恢复的选择** — 合作第一步：让苏轻寒恢复记忆；林凡带她回到长安城裂缝处，利用残余能量冲击芯片；苏轻寒同意尝试
- **第36章：走马灯般的人生** — 芯片失效瞬间，苏轻寒被清除的训练记忆如洪水涌来——6岁被带到管理局、模拟献祭训练、被告知"你的命运就是为时间秩序献身"；她崩溃大哭，林凡紧紧抱住她
- **第37章：觉醒的时督** — 苏轻寒恢复记忆后没有消沉反而爆发惊人力量，时空契合度从99.8%跃升100%突破时督境界；她选择站在林凡一边共同对抗祭品制度
- **第38章：管理局的全面追捕** — 局长得知苏轻寒觉醒后下令抓捕三人；一场大战在管理局总部爆发，苏轻寒用新获得时督级战力一招击溃曾看不起她的特别行动队队长
- **第39章：时间执法系统** — 两个林凡联手对抗局长终极武器"时间执法系统"——能调动所有时间锚点能量；熵减态和熵增态产生前所未有的共鸣形成"时间太极"循环
- **第40章：三方混战** — 时间太极让管理局玻璃幕墙碎裂又重组、整个建筑在时间扭曲中变形；就在执法系统开始崩溃时，黑袍人带残余部队杀到——要在混乱中彻底抹杀所有时间锚点

## 合：时劫新生（第41-50章）

- **第41章：三条战线** — 三方混战全面爆发：林凡对抗黑袍人，未来林凡继续瓦解执法系统，苏轻寒面对局长最后防线；三组战斗在不同时空同步展开
- **第42章：时间净化的终极技能** — 黑袍人发动终极技能要一次性抹除所有时间锚点存在；林凡用熵减态勉强抵挡，但黑袍人的净化之力远超预期
- **第43章：面具之下的真容** — 黑袍人摘下面具——他本人也曾是时间锚点，百年前被时殇"净化"后复活成没有过去也没有未来的"时间幽灵"；他猎杀锚点是为了让他们"解脱"
- **第44章：锚点不是诅咒** — 林凡对黑袍人说："你错了，锚点不是诅咒，是修复时间的钥匙"；这句话动摇了黑袍人百年的信念，他的净化之力出现动摇
- **第45章：未来林凡的消散** — 未来林凡成功瓦解时间执法系统，但代价是自己存在开始不稳定——系统崩溃意味着他所在时间线也将消失；他面临最终选择
- **第46章：五十年的选择** — 未来林凡看着远处的苏轻寒笑了："50年前我没有做出的选择，现在由你来完成"；他选择留下帮助修复时间bug，即使自己将永远消失
- **第47章：时间悖论的终极觉醒** — 两个林凡将时间太极推向极致，直接修复时间本身的"死亡熵增"bug；林凡不再是简单熵减或熵增态，而是成为"时间悖论"本身，身体散发金色光芒
- **第48章：我会替你记住一切** — 修复过程中代价机制启动：林凡开始遗忘——早餐、任务、对话、黑袍人、AI老子、未来林凡……最后看着苏轻寒的脸记忆开始模糊；苏轻寒握住他的手："没关系，我会替你记住一切"
- **第49章：新世界开启** — 修复完成，两个林凡合二为一；祭品制度废除，苏轻寒标记消失，管理局革新为"时间熵值检测"体系；局长退居二线，黑袍人走入新时间线，绯月封印解除消失在月光中
- **第50章：时间极光** — 三个月后，林凡100%契合度成为重点培养对象，苏轻寒是正式搭档；他保留着模糊记忆残片——贴罚单、唐朝剑仙的梦境；AI老子："欢迎来到新规则时代"；苏轻寒喊："别再忘记带早饭了"；林凡走向时间传送器，天际线上出现从未见过的时间极光
