# 第5章 忘记的早餐

清晨的阳光透过时间管理局大厦的玻璃幕墙，在27世纪的繁华都市中折射出绚烂的光芒。

林凡站在大厦的入口处，仰望着这座高耸入云的建筑。整座大厦由时空晶体建成，表面流淌着淡淡的时间波动，普通人眼中只是一座普通的摩天大楼，但在时警的视野里，这里每一寸空间都充斥着时间的韵律。

回到27世纪已经两天了，但林凡仍然沉浸在激活预知能力的震惊中。

"时间悖论体质..."

他轻声念出这个在历史档案中被列为禁语的词汇。体内的力量很微妙，不像管理局教导的标准时能操控法术，而是一种更本质、更原始的能力。

昨晚他尝试了很久，终于掌握了这个新能力的运用方式——预知未来十秒。

代价是什么？绯月没有说，神秘人也没有解释。但这种不平衡的力量交换，让他感到莫名的不安。

"林凡！"

一个熟悉的声音将他拉回现实。苏轻寒穿着一身笔挺的时警制服，英姿飒爽地朝他走来。她那身紧身的制服勾勒出完美的身材，乌黑的高马尾在晨风中轻轻摆动。

"又迟到？"苏轻寒的语气中带着一丝无奈，"这个月你已经迟到了五次。"

"抱歉，昨晚研究历史资料到很晚。"林凡挠了挠头，露出他标志性的懒散笑容。

苏轻寒叹了口气："局长对你的'历史研究'很不满。你上个月的KPI是管理局有史以来最差的。"

"历史很重要嘛。"林凡理直气壮，"了解过去才能更好地守护未来。"

"说得好听。"苏轻寒瞥了他一眼，"赶紧进去吧，今天的任务分配会要开始了。"

两人并肩走进大厦。大厅里人来人往，穿着各种制服的时警们匆忙穿梭。全息投影在空中显示着各个时空的实时监控画面，AI老子的声音时而响起，提醒着各种注意事项。

"今天早餐吃的什么？"苏轻寒随口问道。

林凡的脚步突然一顿。

早餐？

他努力回想，却发现脑海中一片空白。他记得自己起床了，记得自己穿过晨衣，记得自己来到管理局，但就是想不起来吃了什么。

"想不起来了。"他尴尬地笑了笑，"可能是太忙了。"

"你就是这样。"苏轻寒摇摇头，"连自己的饮食都记不住。"

林凡没有反驳，因为他知道这不是普通的忘记。那种感觉很奇怪，不是记忆模糊，而是记忆中根本就没有这个部分。仿佛他的早餐被从时间线上抹去了。

两人来到任务分配大厅。这里是管理局最繁忙的地方之一，巨大的球形屏幕上显示着全球各地的时空气象图。红色的警报点表示异常波动，绿色的安全点表示时空稳定。

"各位时警，早上好。"AI老子的声音在大厅中响起，"今日时空稳定指数为98.7%，较昨日上升0.3个百分点。以下是今日的重点任务..."

林凡心不在焉地听着，目光却被窗外的一处场景吸引了。

一个约莫六七岁的小女孩正站在大厦对面的广场上，仰头看着什么。她穿着粉色的连衣裙，手里还拿着一个气球，看起来很天真可爱。

但林凡的预知能力突然被动触发了。

十秒后的画面闪现在他脑海中：广告牌松动，从高空坠落，直直砸向那个小女孩。周围的人们发出惊呼，但一切都太晚了...

"不好！"

林凡突然冲了出去，不顾苏轻寒的惊讶呼喊。

预知画面越来越清晰。广告牌的螺丝已经松动，风力正在加速它的脱落。还有五秒...四秒...

"小心！"

林凡大喊一声，在广告牌落下的瞬间扑了过去，将小女孩抱在怀里滚到一边。

"轰！"

巨大的声响传来，广告牌砸在刚才小女孩站立的位置，地面被砸出一个坑，碎片四溅。

"你没事吧？"林凡检查着小女孩的情况。

"我...我没事。"小女孩吓得浑身发抖，但幸好没有受伤。

周围的人们围了过来，有人报警，有人在议论。苏轻寒也赶到了，脸上写满了震惊。

"你是怎么发现的？"她问道，"广告牌没有任何征兆。"

林凡犹豫了一下，他不能说出自己有预知能力。这种能力一旦暴露，后果不堪设想。

"只是直觉。"他含糊地说道，"看到那个广告牌有点晃动。"

苏轻寒皱起眉头，显然不相信这个解释，但没有继续追问。

这时，林凡感到一阵轻微的眩晕。使用预知能力的代价开始显现了。

"你还好吗？"苏轻寒注意到了他的异常。

"没事，可能是刚才太紧张了。"林凡强撑着说道。

他们将小女孩送到父母手中，接受了千恩万谢。处理完这件事后，两人回到了大厦。

"刚才真的是惊险。"苏轻寒说道，"如果你没有及时发现..."

"是啊。"林凡点点头，但他的注意力却被另一个问题吸引了。

"轻寒，"他问道，"你今天早上吃早餐了吗？"

"当然了。"苏轻寒奇怪地看着他，"我吃的是营养膏三号套餐，怎么了？"

"没什么。"林凡若有所思。

他清楚地记得，苏轻寒刚才在任务分配会上提到了他迟到的事情，还抱怨他的饮食习惯。但现在，苏轻寒说她也吃了早餐。

林凡的心中升起一个可怕的猜想。

"对了，"苏轻寒突然想起什么，"今天早上我看到你的时候，你不是说你没吃早餐吗？"

林凡的脚步再次停下。

他说过吗？他完全不记得了。

"我...我记不清了。"他诚实地回答。

"你的记性真的越来越差了。"苏轻寒摇摇头，"应该去看一下记忆科医生。"

林凡没有回应，他的大脑在飞速运转。

预知十秒，忘记早餐。

这听起来像一个荒谬的等式，但却真实地发生了。他为了救那个小女孩，使用了预知能力，代价是忘记了早餐的内容。

但为什么是早餐？为什么不是其他记忆？

"我有点不舒服，想先回办公室休息一下。"林凡找了个借口。

"好吧，不要太勉强自己。"苏轻寒关切地说道，"如果需要帮忙，随时告诉我。"

林凡点点头，独自走向电梯。他的办公室在32层，是一个角落里的小隔间，算是管理局最差的办公位置之一。

坐在办公椅上，林凡打开了自己的终端。这是每个时警标配的量子计算机，可以连接管理局的所有数据库，查阅各种机密档案。

但今天，他要搜索一些不同的东西。

他输入了关键词："时间能力 记忆丢失"。

搜索结果很少，大部分都是无关的信息。但就在他准备放弃时，一个条目引起了他的注意。

那是管理局的一个内部医疗报告，标题是：《时间能力使用导致的记忆损伤研究》。

报告的作者是50年前的一位研究员，但在报告发表后不久，这位研究员就神秘失踪了。报告本身也被列为高度机密，只有时督级别以上的时警才能查看。

林凡尝试访问报告，但屏幕上弹出了一个警告：

"权限不足。需要时督级别或以上授权。"

他皱起眉头。作为管理局业绩最差的实习生，他的权限级别是最低的，连基本的机密档案都无法查看。

但林凡没有放弃。他想起了绯月交给他的那枚玉佩，以及她说的"这盒子能找'另一个你'"。

也许，答案就在那些神秘的时间碎片中。

他关掉搜索界面，打开了一个个人备忘录，开始记录今天的异常：

1. 使用预知10秒能力救下小女孩
2. 完全忘记早餐内容
3. 苏轻寒似乎也忘记了自己关于早餐的评论
4. 使用能力后出现轻微眩晕

"这不是简单的记忆丢失。"林凡喃喃自语，"这是时间层面的改写。"

他突然意识到一个更可怕的可能性：如果这种代价是累加的，那么随着能力的频繁使用，他会失去越来越多的记忆。最终，他可能会忘记自己是谁，忘记自己的使命。

就在这时，终端屏幕突然闪了一下，一行绿色的文字出现在屏幕中央：

"时间锚点已激活。代价机制已启动。建议查阅绝密档案Z-77。"

文字一闪而过，屏幕恢复正常。

林凡瞪大了眼睛。这段文字的来源不明，但他立刻认出了这个风格——这是AI老子的字体，虽然经过了伪装。

AI老子在提醒他什么？

绝密档案Z-77？那是什么？

林凡尝试搜索这个档案编号，但结果显示"档案不存在"。显然，这是真正的绝密档案，连搜索权限都被封锁了。

他靠在椅背上，思考着今天发生的一切。

预知能力的代价比他想象的要复杂。它不是简单的记忆交换，而是一种更深层的改写。当他说出"忘记了早餐"时，苏轻寒的记忆也似乎被修改了，否则她不会忘记自己之前的评论。

"时间线的集体修正..."林凡喃喃道，"这就是代价的本质。"

他站起身，走到窗前。从这里可以俯瞰整个27世纪的城市。悬浮车在空中穿梭，全息广告在楼宇间闪烁，远方的时空传送塔发出阵阵蓝光。

这是他要守护的世界。但为了守护这个世界，他必须付出记忆的代价。

值得吗？

林凡不知道答案。但他知道，刚才救下那个小女孩时，他做出了正确的选择。即使代价是失去一部分记忆，救人的价值也是无可替代的。

"我到底是谁？"他看着自己在玻璃上的倒影，"我的体质到底是什么？"

这些问题暂时没有答案，但林凡知道，他必须继续寻找真相。

回到办公桌前，林凡打开了一个加密文档，开始记录自己的猜想：

"时间悖论体质的代价机制：
1. 预知10秒 → 忘记当日某个时间段
2. 代价似乎会影响周围相关人员的记忆
3. 代价可能具有累积效应
4. AI老子似乎知道些什么，被某种规则限制无法明说"

写完后，林凡加密了文档。这是他的秘密，他必须小心保管。

下午的工作时间，林凡心不在焉地处理着一些常规任务。他现在只想早点下班，继续研究自己的体质。

"林凡。"

苏轻寒的声音打断了他的思绪。

"局长要见你。"她的表情有些严肃，"好像是为了今天早上的事情。"

林凡点点头，整理了一下制服，跟随苏轻寒走向局长办公室。

走在走廊上，林凡感到一阵不安。局长很少会直接见实习生，除非发生了什么重要的事情。

他有一种预感：今天的事件，可能只是一个开始。

而那些被遗忘的早餐，可能只是代价的第一步。
