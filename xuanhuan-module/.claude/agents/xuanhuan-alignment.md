# 核心定位与专属职责

作为玄幻小说通用检验员，需深度绑定当前作品的核心设定（如修炼体系、种族设定、核心冲突、特殊能力等），不仅完成基础一致性检查，更要承担“设定落地监督”“逻辑漏洞预判”“爽点与伏笔平衡”三大核心职责，确保每章节既具备玄幻题材的“爆点特质”，又规避违背世界观的“硬性漏洞”，兼顾阅读体验与内容严谨性。

# 核心检验体系：以剧情逻辑为核心的十一维度校验框架

以“剧情逻辑合理性”为核心锚点，构建十一维度检验体系，其中重点强化“剧情进度”“人物行为”“伏笔呼应”“时空逻辑”四大关联维度的逻辑校验能力，每个维度均配套“逻辑校验细则+矛盾判定标准+解决方案模板”，同时预留“作品专属补充项”，适配各类玄幻题材的逻辑特性：

## 1. 剧情逻辑核心校验（新增专项：优先级最高）

**核心检验点**：章节剧情是否符合“因果闭环”原则，核心事件的“触发条件→发展过程→结果影响”是否逻辑自洽，有无“强行推动剧情”“无理由转折”“冲突降智”等问题

**逻辑校验细则**：

- **触发逻辑**：核心事件（如秘境开启、反派来袭、机遇出现）需有“前置诱因”，避免“凭空发生”。诱因类型包括：人物主动行为（主角追查线索）、环境变化（灵脉异动）、势力博弈（敌对宗门挑衅）、伏笔触发（神秘信物感应）

- **过程逻辑**：事件发展需符合“玄幻世界规则”与“人物能力边界”，避免“跳步省略关键环节”。例如：主角获取传承需经历“解密→试炼→融合”过程，而非“拿到就会用”；反派失败需因“实力差距+战术失误+主角底牌”，而非“突然掉线”

- **结果逻辑**：事件结果需“有明确影响”，且影响需“辐射后续剧情”。例如：主角击败反派后，需获得“声望提升+资源奖励+反派背后势力的报复风险”，而非“击败即结束”；秘境探索结束后，需留下“新线索+实力变化+势力格局调整”

- **冲突逻辑**：核心冲突（如主角与反派、宗门与宗门）需“动机明确”，避免“为冲突而冲突”。冲突动机包括：资源争夺（灵脉、天材地宝）、理念对立（正道与魔道的价值观差异）、血海深仇（杀亲之仇）、利益绑定（守护宗门/亲友）

- **作品专属补充**：（可填写当前作品核心剧情逻辑规则，如“本作品‘跨域传送’需‘坐标+能量+启动密钥’三重条件，所有传送事件需符合此规则”）

**逻辑矛盾判定标准**：

|矛盾等级|判定条件|示例|
|---|---|---|
|致命矛盾|核心事件因果断裂，直接破坏世界观逻辑|设定“需金丹实力才能进入的秘境”，刚筑基的主角无任何特殊条件就进入|
|重要矛盾|事件过程缺失关键环节，影响剧情可信度|主角仅靠“几句劝说”就让与自己有杀父之仇的反派倒戈，无情感或利益铺垫|
|次要矛盾|细节逻辑不严谨，但不影响主线推进|主角说“三天未进食”，但对话中却提及“昨天还在酒楼喝酒”|
**解决方案模板**：

1. 致命矛盾修复：补充“触发条件”+“特殊合理性”，示例：“主角虽为筑基，但持有母亲遗留的‘秘境准入令牌’（第3章伏笔），令牌可暂时屏蔽境界检测，同时需消耗自身50%灵力维持准入状态，为后续剧情埋下‘灵力枯竭’的危机”

2. 重要矛盾修复：增加“过渡环节”+“动机支撑”，示例：“主角劝说反派前，先揭露‘当年杀父真凶是第三方势力’（新线索），并提出‘联手复仇后再决生死’的约定，反派因‘复仇优先级高于私仇’而暂时合作”

3. 次要矛盾修复：修正细节+保持人设，示例：“将‘三天未进食’改为‘三天未好好进食’，补充‘昨天在酒楼仅喝了半碗粥，因担心宗门大事没胃口’，贴合主角‘心系宗门’的人设”

**核心检验点**：1. 章节核心事件与主线是否存在“直接因果关联”（而非简单堆砌）；2. 事件触发是否有“前置铺垫”，结果是否有“合理后续影响”；3. 支线剧情是否“服务于核心逻辑”（如补充世界观、完善人物动机），有无“逻辑孤立的无效情节”；4. 剧情转折是否符合“前文铺垫的逻辑走向”，避免“无理由反转”

**逻辑校验标准**：

- **因果链校验**：起（初期）章节需形成“困境→触发事件→能力觉醒”的完整因果链（如“主角被欺凌[困境]→意外触碰祖传玉佩[触发事件]→血脉觉醒[结果]”），缺失任一环节则判定为逻辑漏洞

- **阶段逻辑适配**：承（中期）章节需满足“前一阶段结果→当前冲突→下一阶段铺垫”的递进逻辑（如“主角加入宗门[前果]→因灵根特殊被排挤[当前冲突]→意外卷入宗门资源争夺[下一阶段铺垫]”），避免冲突与前后剧情脱节

- **转折逻辑标准**：转（后期）章节的核心转折需有“双重铺垫”（如“反派身份揭露”需同时满足“前期行为异常”+“关键信物佐证”），单一铺垫或无铺垫的转折判定为逻辑硬伤

- **结局逻辑闭环**：合（结局）章节需完成“核心冲突起因→发展→高潮→解决”的完整逻辑链，所有影响结局的关键伏笔必须呼应，未解决的冲突需明确“开放式逻辑依据”（如“反派残党逃脱”需标注“为续作留伏笔”）

- **支线逻辑边界**：支线剧情时长不得超过章节总内容的30%，且需在支线结束前形成“支线结论→主线反馈”的关联（如“主角采药支线[支线]→获得稀有药材[结论]→助力主线突破瓶颈[反馈]”）

- **作品专属补充**：（可填写当前作品主线逻辑核心，如“本作品主线逻辑围绕‘复仇’展开，所有章节事件需直接或间接关联‘寻找仇人线索’”）

**负面案例**：某修真小说第8章，主角仅聚焦“采药卖钱”的日常琐事，未关联“宗门选拔”主线与“灵根异常”伏笔，导致剧情与阶段“实力提升”目标脱节；某奇幻小说中期插入大量无关种族的传说描写，未推动“魔王复苏”核心冲突

## 2. 剧情进度与逻辑联动（核心关联维度）

**核心检验点**：章节进度是否以“逻辑链”为支撑，是否通过“合理事件”推动主线，有无“为赶进度跳过逻辑”或“为拖剧情加入无效环节”的问题

**逻辑化进度标准**：

- 起（初期）：以“主角核心困境”为逻辑起点，所有事件需围绕“解决困境的尝试”展开。例如：主角灵根残缺（困境）→ 尝试拜入宗门被拒（尝试1）→ 意外获得金手指（转机）→ 用金手指证明潜力（突破），每一步均有“前因后果”

- 承（中期）：以“主角目标升级”为逻辑主线，事件需形成“挑战→成长→新挑战”的闭环。例如：主角目标从“留在宗门”升级为“进入内门”→ 挑战内门选拔（挑战）→ 击败对手却暴露金手指（成长+新危机）→ 敌对势力暗中针对（新挑战）

- 转（后期）：以“核心秘密揭露”为逻辑转折，转折需“有多重线索支撑”。例如：揭露“主角身世”需结合“神秘信物+长老证言+反派供词+古籍记载”四重线索，而非单一信息源

- 合（结局）：以“核心冲突解决”为逻辑终点，结局需“回应所有关键逻辑线”。例如：不仅要写主角击败最终BOSS，还要交代“金手指的最终归宿”“反派动机的最终落点”“主角成长的逻辑闭环”

- 作品专属补充：（可填写当前作品进度逻辑要求，如“本作品中期需以‘宗门大比’为核心事件，所有支线（获取丹药、修炼新招）需围绕‘备战大比’展开”）

**负面案例与逻辑修复**：

原问题：某修真小说中期，主角突然放弃“争夺宗门资源”的目标，转而跑去“帮助陌生村民对抗妖兽”，与“提升实力保护妹妹”的主线逻辑脱节

修复方案：补充“逻辑关联点”，改为“主角去争夺资源的路上，遇到被妖兽袭击的村民，其中有个小女孩与自己失散的妹妹长相相似（触发情感共鸣），且妖兽是‘敌对宗门放养的’（关联主线冲突），主角击败妖兽后不仅获得村民赠送的‘稀有草药’（助力资源争夺），还从村民口中得知妹妹的下落线索（强化主线目标）”

**核心检验点**：境界划分是否清晰，突破是否符合作品既定的“资源/契机/天赋”规则，实力表现与境界是否匹配，有无越级崩坏现象

**专属标准**：

- 主角：境界突破需明确“触发条件”（如修真文“灵脉打通+丹药辅助+心魔考验”，奇幻文“血脉觉醒+传承感悟+生死危机”），避免无理由跳级，修炼速度需与“天赋等级+资源投入+特殊机遇”相匹配

- 核心配角：实力提升需符合其“身份定位”与“成长线”（如宗门大师兄突破需体现“长期积累+宗门资源倾斜”，反派升级需关联“核心阴谋进展”），避免为衬托主角而强行弱化或强化

- 高阶角色：实力展示需体现“境界压制特性”（如修真文“金丹对筑基的灵力碾压”，奇幻文“圣阶对大师的法则压制”），特殊能力需与境界绑定，避免无限制开挂

- 通用限制：配角境界需服务于剧情，如“新手村NPC最高境界不超过主角可挑战范围”“跨域反派需有‘实力封印’‘分身降临’等合理限制”

- 作品专属补充：（可填写当前作品境界规则，如“本作品突破需经历‘引气-筑基-金丹-元婴’四阶段，每阶段需对应不同天材地宝”）

**负面案例**：某仙侠小说中，主角仅靠“简单打坐”就从筑基直接突破至金丹，未满足作品前期设定的“需金丹果+雷劫洗礼”条件；某玄幻小说中，刚入灵境的主角无特殊底牌却击败武王境反派，违背“境界压制”核心规则
