# 短剧剧本创作技能包

[技能名称]
短剧剧本创作技能包 (script-skill)

[功能描述]
专业的短剧剧本创作技能，基于标准过稿模式和行业规范，为用户提供高质量的短剧剧本创作服务。该技能严格遵循剧本格式标准，确保输出内容符合短剧平台的要求。

[核心能力]
1. **小说转剧本能力**：能够将已有的小说作品改编为对应的短剧剧本
2. **格式标准化**：严格遵循行业标准的剧本格式规范
3. **节奏把控**：掌握短剧特有的快节奏、强冲突、高反转的创作要点
4. **钩子设计**：精通每集结尾的付费点（付fei卡点）设计技巧
5. **视觉化呈现**：通过场景、动作、镜头语言等专业手法，增强剧本的画面感

[文件结构]
```
script-skill/
├── SKILL.md                     # 技能包主文件
├── outline-method.md            # 剧本大纲创作方法论
├── output-style.md              # 剧本写作风格指南
├── templates/                   # 剧本模板目录
│   ├── script-outline-template.md    # 剧本大纲模板
│   ├── script-episodes-template.md   # 分集剧本模板
│   └── script-scene-template.md      # 单场景模板
└── examples/                    # 剧本示例目录
    ├── script-outline-example.md     # 剧本大纲示例
    └── script-episodes-example.md    # 分集剧本示例
```

[输出格式标准]
```
剧名《xxx》
集数: X集
编剧: xxx

一、剧情简介
[200字左右，快速传达故事核心创意]

二、人物小传
[主要角色的年龄、外貌、性格简介]

三、大纲
[1500字左右，详细的故事走向，标注付fei卡点]

四、正文
[分集剧本，每集1000-1500字]
```

[执行流程]

1. **剧本大纲创作阶段**
   - 读取用户选择的原著小说
   - 加载 resources: script-outline-template + outline-method + output-style + script-outline-example
   - 创建剧本大纲文件

2. **分集剧本创作阶段**
   - 读取剧本大纲和原著小说
   - 加载 resources: script-episodes-template + output-style + script-episodes-example
   - 创作每集剧本内容

[质量标准]
- 格式完全符合行业标准
- 每集必须有明确的付费卡点
- 对话自然，符合人物性格
- 场景转换流畅，节奏紧凑
- 镜头语言专业，画面感强

[注意事项]
- 保持与原著小说的核心设定一致性
- 合理删减次要情节，突出主线
- 增强戏剧冲突，放大人物情感
- 严格遵循短剧的创作规律

[调用方式]
当Agent需要创作剧本时，自动调用此技能包获取专业指导。
